The first release of **Volume Tabs**, an open-source volume booster for Chrome and Firefox. Make any tab louder, up to 500%, without giving an extension your data.

## Features

- **0% to 500% volume per tab**, in 1% steps: slider, mouse wheel, arrow keys, or type the number.
- **Sound modes:** Default (untouched), Voice for clearer dialogue and podcasts, Bass for music.
- **Playing tabs list:** every tab that is playing audio, with its level. Click one to switch to it.
- **Per-site memory:** remembers the level you used on each site. Restore it in one click, or reset to 100%.
- **Keyboard shortcuts:** `Alt+Shift+Up` / `Alt+Shift+Down` change the volume by 10%, `Alt+Shift+0` resets it.
- **Toolbar badge** with the current level of each tab.
- **Light and dark themes**, English and Turkish.
- **Fullscreen keeps working in Chrome** in most cases: page audio is used first, and tab capture only when needed.

## Privacy

- No data collection, no analytics, no network requests, no remote code.
- No dependencies and no bundler: the packaged code is exactly the code in `src/`.
- A page is only touched when you open the popup on that tab.

See [PRIVACY.md](https://github.com/cngil/volume-tabs/blob/main/PRIVACY.md) and [SECURITY.md](https://github.com/cngil/volume-tabs/blob/main/SECURITY.md).

## Install

Store listings are not published yet. Download the package for your browser below.

**Chrome, Edge, Brave** (`volume-tabs-chrome-1.0.0.zip`)
1. Unzip the file.
2. Open `chrome://extensions` and turn on *Developer mode*.
3. Click *Load unpacked* and select the unzipped folder.

**Firefox** (`volume-tabs-firefox-1.0.0.zip`)
1. Open `about:debugging#/runtime/this-firefox`.
2. Click *Load Temporary Add-on* and select the zip file.

This package is not signed by Mozilla yet, so Firefox removes it when it restarts, and installing it by double-clicking shows "not verified". A signed version will follow.

## Known limitations

- **Firefox:** there is no tab capture API, so DRM-protected media (for example Netflix or Spotify) and cross-origin media without CORS cannot be boosted.
- **Chrome:** on sites where tab capture is needed, Chrome keeps fullscreen video inside the window while the tab is captured.
